# Contributing / Katkı

Use Node 24.13+ below 25. Run `npm ci --ignore-scripts`, `npm run check`, `npm audit --audit-level=low`. Keep tests offline with synthetic identifiers and fake interaction/terminal adapters. Never commit `.env`, tokens or personal reports. Add meaningful regression tests for arithmetic, permission/binding and lifecycle changes. Keep both README languages accurate, preserve private-only operation and minimum permissions, and review dependency licenses. PRs run three-OS CI without Discord credentials. Live operator checks are separate from automated evidence. Contributions use the repository's MIT license.

Node 24.13+ (25 öncesi) kullanın. `npm ci --ignore-scripts`, `npm run check`, `npm audit --audit-level=low` çalıştırın. Testler sentetik kimlikler ve sahte etkileşim/terminal bağdaştırıcılarıyla çevrimdışı kalmalı. `.env`, token veya kişisel rapor commit etmeyin. Aritmetik, izin/bağlama ve yaşam döngüsü değişikliklerine anlamlı regresyon testi ekleyin. README'nin iki dilini doğru tutun; yalnızca özel yanıtları, minimum izinleri koruyun ve bağımlılık lisanslarını inceleyin. PR CI üç işletim sisteminde Discord kimlik bilgisi olmadan çalışır; canlı operatör denemesi ayrı bir doğrulamadır. Katkılar MIT lisansıyla sunulur.
