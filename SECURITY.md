# Security / Güvenlik

Do not post tokens, private IDs or reports in issues. Rotate exposed tokens in the Developer Portal immediately. For a vulnerability, use GitHub private vulnerability reporting if the repository enables it; otherwise contact the maintainer through a private channel they publish. If none exists, open an issue asking for a private reporting channel without exploit details or secrets. No response-time promise. Review MIT's warranty terms.

Token, özel ID veya raporları issue'lara koymayın. Sızan tokenı Developer Portal'da hemen yenileyin. Açık bildiriminde depo etkinleştirmişse GitHub özel güvenlik bildirimi kullanın; aksi halde bakımcının yayımladığı özel iletişim kanalını kullanın. Böyle bir kanal yoksa istismar ayrıntısı veya gizli bilgi vermeden özel bildirim kanalı isteyen issue açın. Yanıt süresi garantisi yoktur; MIT garanti hükümlerini inceleyin.
